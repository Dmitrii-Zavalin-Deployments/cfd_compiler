# 📐 CFD Compiler

## 🧩 CAD → Spatial Location → Physical Boundary Pipeline
A high‑fidelity scientific CFD compiler designed for CAD/STEP geometries, 
spatial location mapping, physical boundary parsing, and solver preprocessing.
